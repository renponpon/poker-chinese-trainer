# Phrabit X フォロー候補リスト 2026-07

目的: 新設した `@phrabit_app` の体裁を整えつつ、Phrabit に近いユーザー・発信者・公式アカウントとの接点を作る。

## 前提

- 目標は「フォロー数100以上」ではなく、最終的には「関連性のあるフォロワー100以上」。
- 新規Xアカウントは制限が出やすいため、一気に100フォローしない。
- 目安は1日15〜30フォロー、いいね・返信も少量にする。
- フォロー前にプロフィール、直近投稿、外部リンク、スパム感を確認する。
- フォロー返し目的の無差別フォローは避ける。

## 優先順位

1. **公式・サービス系**: 体裁づくりに有効。フォローバックは期待しない。
2. **英語・中国語学習の個人発信者**: フォローバック・交流の可能性がある。
3. **海外生活・留学・ワーホリ・接客系**: Phrabit の利用文脈に近い。
4. **検索で拾った関連候補**: プロフィール確認後に採用。

## H. フォロー時の判断基準

フォローしてよい:

- 直近30日以内に投稿がある。
- 語学、海外生活、留学、ワーホリ、接客、旅行の文脈がある。
- プロフィールが自然で、外部リンクや投稿内容に違和感がない。
- Phrabitの固定ポストに反応しそうな課題を持っている。

避ける:

- 投稿がスパム、懸賞、投資、アダルト、政治煽り中心。
- フォロワー購入・相互フォロー募集だけのアカウント。
- プロフィールや投稿から言語学習との関連が薄い。
- 公式っぽい名前だが外部リンクが不自然。

## I. フォロワー100人に近づける実務

フォローだけではフォロワー100人は達成しにくい。最短で体裁を整えるなら、以下も同時にやる。

1. 既存の個人アカウントで `@phrabit_app` の固定ポストを引用RTする。
2. 知人・既存ユーザーに「開発用アカウント作ったのでフォローだけお願いします」と頼む。
3. 上記候補の投稿に、1日3〜5件だけ自然な返信をする。
4. 返信は宣伝ではなく「その場で言えなかった英語/中国語あるある」に寄せる。
5. 3〜5日後に、固定ポストとは別に参加型投稿を出す。

## J. 返信例

宣伝臭を弱める返信テンプレ。

- これ、まさに現地で一度言えないと次も言えないやつですね。こういう「言えなかった一言」を残して復習できる形を作っています。
- 海外生活だと、単語より「その場で言いたかった一文」のほうが記憶に残りますよね。
- 接客英語は場面ごとの言い回しが強いので、あとから自分用にドリルできるとかなり効きそうです。
- 中国語はピンインまで含めて残せると、次に口から出しやすくなりますね。

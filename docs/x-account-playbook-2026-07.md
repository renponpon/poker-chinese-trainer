# Phrabit X専用アカウント運用プレイブック

**作成日**: 2026-07-08  
**目的**: Phrabit 専用Xアカウントを作り、海外生活・留学・出張・接客で「翻訳したけど次に言えない」潜在ユーザーへ直接アプローチする。  
**位置づけ**: バズ狙いではなく、刺さる層を発見するための接点づくり。

---

## 1. アカウントの役割

専用アカウントの目的は、単体で大量集客することではない。

役割は次の4つ。

1. Phrabit が何のツールかを説明する
2. 潜在ユーザーの困りごと投稿に返信する
3. 実際の使い方・入力例・改善ログを見せる
4. 反応した人とDM・リプで会話する

既存の個人アカウントは初速の信用に使う。  
専用アカウントは継続接点に使う。

---

## Duolingoから参考にすること

Duolingoをそのまま真似しない。  
Phrabitが借りるのは、キャラクターや口調ではなく次の運用構造。

| Duolingoの強み | Phrabitでの置き換え |
|---|---|
| 毎日触れる理由を作る | 「今日言えなかった一言」を投稿・入力の入口にする |
| 学習の面倒さを軽く見せる | 翻訳→保存→ドリルを1つの短い流れとして見せる |
| ユーザー参加を促す | 「最近言えなかった一言」をリプ・引用・入力で集める |
| 投稿テーマが一貫している | 「訳して終わらせない」を全投稿の軸にする |
| 文化・日常ネタに乗る | 海外生活・留学・出張・接客の具体場面に寄せる |
| 反復接触が多い | 固定ポスト、例文投稿、返信、改善ログを継続する |

### 参考にしないこと

- 過度な脅し・煽り
- 死亡ネタなど文化差が大きいジョーク
- ユーザーを馬鹿に見せる表現
- 翻訳精度への信頼を損なう過激な言い回し
- バズだけ狙ってプロダクトの利用に繋がらない投稿
- 強いキャラクター口調
- 公式感を損なう内輪ノリ

Phrabitはまだ初期検証段階なので、まずはオーソドックスな信頼感を優先する。  
Duolingo的な要素は、キャラではなく「習慣化・参加・反復・一貫性」として取り入れる。

### 返信テンプレ

返信は、相手の困りごとを解決するだけで成立する内容を基本にする。初回返信の8割以上はリンクを貼らず、具体的な表現や短い共感を返す。

困りごとが具体的な投稿:

```text
この場面なら「（自然な英語・中国語）」が使いやすいと思います。
（必要なら、丁寧さや場面による違いを1文だけ補足）
```

英語・中国語が出てこない投稿:

```text
この「分かるのに、その場では出てこない」感じありますよね。
次に同じ場面がありそうなら、言いたかった一言だけ残して短く言い直す練習が合いそうです。
```

学習が続かない投稿:

```text
教材の例文より、自分が実際に言えなかった一言の方が覚える価値があるかもと思って、
レッスン後にその一言だけ言い直しておくと、次回かなり使いやすくなりそうです。
```

相手が反応した場合、または保存・復習の必要性が明確な場合の2通目:

```text
こういう「実際に言えなかった一言」を翻訳→保存→ドリルにつなげるPhrabitという試作品を作っています。
もし次回までに練習してみたければ、この一言で試せます。
https://phrabit.com/?ref=x_reply_202607
```

```text
オンライン英会話や言語交換の後なら、言えなかった一言を次回まで短く復習できます。
Phrabitでその流れを試せるので、必要ならどうぞ。
https://phrabit.com/?ref=x_reply_online_lesson_202607
```

### 返信で避けること

- いきなり「使ってください」とだけ言う
- 相手の悩みに触れずURLだけ貼る
- 同じ文面を大量投下する
- 医療・法律・重大トラブルに強い断定で踏み込む
- 競合ツールを下げる
- 相手の失敗を強くいじる
- 悩みが重い投稿にネタ返信する

## 9. 見るべき指標

| 指標 | 判断 |
|---|---|
| フォロー数 | 参考程度 |
| いいね | 共感の参考 |
| リプ | 悩みの具体性を見る |
| URLクリック | 興味の参考 |
| フレーズ入力 | 最重要 |
| 保存 | 強い価値サイン |
| ドリル開始 | 学習意欲サイン |
| 翌日再訪 | 継続可能性サイン |
| 実会話・レッスン後の追加登録 | 最重要。自然な利用習慣が成立したサイン |

専用アカウントの目的はフォロワー増ではない。  
**どの層が実際に入力し、実会話の後にもう一度追加するか**を見る。

## 10. 2週間後の判断

続ける条件:

- X返信経由でフレーズ入力が発生する
- 1つ以上のセグメントで保存・ドリルが出る
- リプやDMで具体的な利用場面が出る

方向転換する条件:

- いいねはあるが入力がない
- クリックはあるが保存がない
- 「便利そう」だけで具体例が出ない
- どの層にも翌日再訪がない

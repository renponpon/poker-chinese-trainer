# Open Questions

最終更新: 2026-09-07

## 9月の決定事項と未確定事項

決定済み: 海外生活者を主対象とし、翻訳・ニュアンス調整・保存・ドリル・ログイン同期の基本フローを無料で維持する方針。国内レッスン層への主対象変更や基本機能の一律有料化は行わない。

9月7日回答済み：翻訳・解説・音声APIは月3,000円。中国・マカオ・香港・台湾などで中国語、英語を生活で使う地域で英語を対象とし、英中の優先度は同じ。地域と言語の再選択を本人へ求めない。現在の実装は普通話・簡体字/米語中心であり、両言語・全地域の同等品質が実証済みという意味ではない。

| 未確定の問い | 確認方法 |
|---|---|
| 目標月間利益と達成期限は何か | 本人の希望を確認。未定の間は月次の運営黒字化を暫定目標にし、旧資料の売上目安や月3,000円のAPI予算と混同しない |
| 1万人利用は累計か月間か | 長期の希望として保持し、集計定義と期限を確認。roadmapでは累計初回実利用と直近30日の実利用を別記する |
| 当月残額とprovider別の停止設定はどうなるか | 当月実費・API固定料金・共有課金・通貨を管理画面で確認し、roadmapの月3,000円設定案を具体化。まだ設定済みではない |
| 普通話・簡体字中心で各地域の生活用途に合うか | 香港/マカオの普通話利用場面、台湾の表示、本土の回線を実地確認。英語も現地の語調・接続を同じ基準で確認 |
| 生活で必要になる頻度と、復習へ戻る頻度はどの程度か | 初回利用者を分母に、別日の復習・新規追加を紹介元別に確認 |
| 原価を抑えながら基本体験が成立する無料枠はどこか | provider別利用量、実請求、無料・有料想定者別の原価を確認。先に回数制限を変更しない |
| 追加生成枠に実際に払う人がいるか | 継続利用者へ内容・価格を具体化して提示。興味、購入、翌月更新を区別 |
| 月980円などの価格が適切か | 現時点では仮説。無料枠・有料枠と原価が分かるまで販売条件を確約しない |
| 教室が紹介したいことと費用を負担したいことは一致するか | 紹介実施と支払い提案を別々に記録 |
| 無料利用者の原価も含めて利益が残るか | 売上から全利用者のAPI・決済・固定費・紹介料・集客費を控除。作業時間も別記 |

以下の7月時点の比較仮説は参考。現在の実行順序は `docs/roadmap.md` を優先する。

この文書は、Phrabit の資料統合で見つかった未確定事項、矛盾しうる情報、検証が必要な問いをまとめます。推測は推測として扱い、事実や決定済み事項と混ぜないための作業メモです。

## 判定基準の候補

| 検証対象 | 見たいシグナル |
|----------|----------------|
| 初回価値 | 既存翻訳ではなく Phrabit を開いた理由が語られる |

## 最初の判定ライン

現在の仮置きは `docs/roadmap.md` と `docs/segment-marketing-experiment-2026-07.md` に置く。主な最低ラインは以下。

| 指標 | 仮の最低ライン |
|------|----------------|
| フレーズ入力者 | 1セグメントで5人以上 |
| 保存 | 1セグメントで2人以上 |
| ドリル開始 | 1セグメントで1人以上 |
| D1再訪 | 1セグメントで1人以上 |
| D7再訪 | 1セグメントで1人以上 |
| 会話後の自発追加 | 1セグメントで1人以上。複数人なら強いシグナル |
| 開く理由 | 既存翻訳ではなく Phrabit を開く具体的理由が3件以上 |

この数値は検証を締めるための初期ラインであり、プロダクトの合否を単独で決めるものではない。発話、利用場面、使われなかった理由とセットで判断する。

# User Segments

最終更新: 2026-09-07

## 現在の選定（2026-09-05）

主対象は「海外生活で現地語を繰り返し使い、次は自分で言いたいと考え、既に学習・メモ・調べ直しをしている日本人」。国内レッスン受講生への転換は採用しない。

現地の教室・個人講師・生活コミュニティは、この対象へ紹介してもらう経路。教室に通っていること自体を支払い意思の証拠にしない。海外在住でも翻訳だけで十分な人は優先しない。

2026-09-07合意：中国・マカオ・香港・台湾などで中国語、英語を生活で使う地域で英語を使う日本人を同じ優先度で扱う。現実装の中国語は普通話・簡体字中心で、広東語や繁体字選択への対応済みを意味しない。地域よりも「実際の相手に使う言語」と繰り返す生活場面で対象を確認し、募集・判定基準は英中共通にする。

以下には7月時点の比較候補も残すが、9月の対象選定ではこの節を優先する。生活上の発話需要、聞き取り需要、学習意欲、継続利用、支払い意思は分けて確認する。

この文書は、Phrabit の対象ユーザーを、初期ビーチヘッド、拡張候補、対象外に分けて整理します。資料上の事実と仮説を混ぜないよう、検証状態も併記します。

## セグメント整理の前提

Phrabit は「中国語を勉強したい人全員」向けではありません。

中心に置くのは、日本語を主言語にしつつ、海外現場で短い言葉が出ず、翻訳した内容を次に自分で言える状態へ戻したい人です。

## 現在の優先条件

現在は「留学生」「駐在員」といった属性名だけではなく、次の条件を多く満たす人を優先する。

1. 週1回以上、外国語を実際に使う場がある
2. 直近に言えなかった具体的な一言がある
3. 同じ相手・場面・レッスンが再び来る
4. 次回は自分の言葉で言いたい
5. 会話やレッスン後に短く記録するタイミングがある

2026年7月にはレッスン層も並列で扱った。9月からは海外生活・駐在帯同・ワーホリ・留学の実生活で上記条件を満たす人を優先する。

## 追加検証: オンライン語学レッスン・言語交換利用者

### 定義

オンライン英会話、オンライン中国語、italki、Tandem、HelloTalkなどを定期的に利用し、実際に外国語で話す機会がある日本語話者。

### 代表的な場面

- レッスン中に言いたいことが出ず、日本語や簡単な表現で済ませる
- 講師に直された表現をメモしたまま復習しない
- 次のレッスンでも同じ表現に詰まる
- レッスンノートやチャット履歴が散らばる

### 強い理由

- レッスン終了後という記録タイミングが明確
- 次回レッスンという復習期限がある
- SNSで学習記録を公開する人が多く、対象を発見しやすい
- 次回に実際に言えたかを短期間で確認できる

### 検証状態

有力仮説だが、Phrabitでの入力・保存・翌日再訪は未検証。一般的な「語学学習中」だけでなく、定期的な実会話がある人に絞って反応を見る。

## 初期検証市場: 海外ライブポーカー日本人

### 定義

マカオや中国語圏でライブポーカーをする日本人。特に、中国語や英語が分かる・言えることに、損失回避、会話参加、関係構築の価値を感じる人。最初の実地検証市場としては有効だったが、2026年6月のX告知後に継続利用がほぼ残らなかったため、現在の主獲得対象からは外している。

### 代表的な場面

- 卓上で席、順番、ルール、相手の発言を確認する
- フロアやスタッフに状況を説明する
- レストランや移動で短い会話をする
- 中国人プレイヤーの輪に入る
- 英語押し切りで通じない、または微妙な空気が残る

### Good signal

- 直近の具体的な困りごとが出る
- 金銭損失、機会損失、疎外感、悔しさが語られる
- 「次は自分で言いたい」が出る
- 翻訳した一言を保存・復習したいと言う

### Bad signal

- 「英語で十分」
- 「翻訳で困っていない」
- 「中国語になりたい自分がない」
- 具体的な場面が出ない

## 拡張候補: 中国出張ビジネス層

### 定義

日本在住または日本法人所属で、直近12か月以内に業務で中国語圏へ渡航し、現地で口頭コミュニケーションが発生した人。

### 代表的な場面

- 会議
- 工場・現場確認
- 現地スタッフへの指示
- 接待
- 税関・移動
- 仕様や条件の確認

### 想定課題

- 言いたいことは日本語で明確だが、中国語や英語で自然に出ない
- 翻訳文のニュアンスや責任範囲が不安
- 専門用語を保持したい
- その場限りでなく、次の出張でも使いたい

### 検証状態

仮説段階です。`docs/crowdworks-interview-recruitment.md` で募集条件と除外条件が整理されています。

## セグメント横断の見方

Phrabit が強く刺さるユーザーは、属性ではなく次の条件で見ます。

1. 直近の現場エピソードがある
2. 言えなかった一言が具体的にある
3. 既存解に不満がある
4. 次に自分で言えるようになりたい
5. 保存・復習・再訪の行動が起きる
6. 実会話後に自発的な追加フレーズ登録が起きる

根拠:

- `docs/interview-playbook.md`
- `docs/interview-observation-sheet.md`

## 一文定義

Phrabit は、海外現場で調べた短いフレーズを、翻訳・保存・復習し、次に自分で言える言葉へ変えるアプリです。

短いコピーとしては、以下が現在の訴求に最も近いです。

> 現地で訳したフレーズを、次は自分の言葉に。

## コア価値

1. 翻訳で終わらせない

   Google 翻訳や ChatGPT で調べた一言を、その場限りの理解で終わらせず、次に自分で言える状態へ近づける。

2. ユーザー固有の現場フレーズを残す

   一般教材の例文ではなく、ユーザー自身が現場で必要になった表現を、個人のライブラリとして蓄積する。

3. 翻訳・読み・使い方・保存・ドリルをつなぐ

   訳文だけでなく、ピンイン/読み、使う場面、自然な言い方、復習までを一連の流れにする。

4. 翻訳アプリと学習アプリの間の空白を埋める

   既存翻訳ツールは「調べる」には強く、Anki は「反復」には強い。Phrabit は、現場で調べた一言を反復対象へ変える部分に価値を置く。

## 対象ユーザー

### 初期検証市場と現在の獲得対象

海外ライブポーカー日本人は、Phrabit の最初の実地検証市場として扱った。開発者が利用場面を直接観察でき、英語・中国語の短い一言が繰り返し発生する点では有効だった。

一方、ポーカーアカウントでの告知は初日にフレーズ入力が発生したものの、2週間後の継続利用はほぼ残らなかった。この結果から、ポーカープレイヤーという属性だけでは、保存・ドリル・再訪が自然に起きる主要獲得セグメントとは確認できていない。

現在は、言語や趣味ではなく、次の行動条件で対象を選ぶ。

1. 外国語を実際に使う機会が継続的にある
2. 「言いたかったのに言えなかった一言」が最近発生している
3. 翻訳で済ませるだけでなく、次は自分で言いたい
4. 会話後やレッスン後に、保存・復習へ戻る自然なタイミングがある

この条件に合う現在の優先候補は、海外生活・留学・ワーホリ中の人、定期的にオンライン語学レッスンや言語交換をする人、海外出張・駐在・帯同生活で外国語を繰り返し使う人とする。ポーカー層は検証知見を得やすい小さな利用場面として残すが、当面の主な獲得対象にはしない。

## 解決する課題

中心課題:

> 翻訳でその場は理解できるが、次の会話で自分の口から出てこない。

課題はセグメントごとに入口が違います。

| セグメント | 課題の入口 |
|------------|------------|
| ポーカー層 | 卓上、フロア、レストランで言い通せない。損失や疎外感につながる |
| 出張・業務層 | 会議、工場、現地スタッフへの指示でニュアンスや責任範囲がずれる |
| 駐在・生活層 | 日常会話、注文、問い合わせ、聞き取りで毎回詰まる |
| オンラインレッスン・言語交換層 | レッスン中に言えなかった表現を復習せず、次回も同じ表現に詰まる |
| 学習高動機層 | 単語や文法は知っていても、会話速度で反射的に出ない |

根拠:

- `docs/customer-understanding-synthesis.md`
- `docs/jtbd-product-jobs-draft.md`
- `docs/interview-playbook.md`
- `docs/interviews/*.md`

## 現在のプロダクト範囲

| 範囲 | 状態 |
|------|------|
| 翻訳 | 中核機能。通常はDeepL→失敗時Azure、品質はGemini 3.5 Flash-Lite。2026-09-07本番反映済み |
| 読み・ピンイン | 中国語では重要な補助情報 |
| 使い方・解説 | 品質モードやドリル追加時の価値 |
| 保存 | ライブラリ化の中心 |
| ドリル/SRS | 次に言える状態へつなぐ |
| 会話補助 | 会話中に翻訳する。ただし自動保存しない |
| 利用計測 | provider、mode、feature、source_page などで計測する |
| 多言語 | 中国語と英語に対応しうる構造がある |

- 会話中の翻訳を自動でライブラリ保存しない

## 現在フェーズ

現在は、海外生活者に対象を固定し、現地の紹介経路を通じた利用と基本無料の継続価値を確かめるフェーズです。2026年7月時点の広範なセグメント比較は参考とし、実行順序は `docs/roadmap.md` の2026年9月方針に従います。

直近では、次の問いが重要です。

- Google 翻訳や ChatGPT ではなく Phrabit を開く理由があるか
- 翻訳後に保存するか

- D1/D7 で再訪するか
- 実会話やレッスンの後に、自発的に新しいフレーズを追加するか
- 海外生活、留学・ワーホリ、オンラインレッスン、出張・駐在のどこで最も強く行動が起きるか

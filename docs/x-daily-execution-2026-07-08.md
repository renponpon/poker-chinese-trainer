## 投稿案

### 投稿1: 課題共感

```text
翻訳アプリでその場は解決できても、
次に同じ場面でまた言えないことがある。

Phrabitは「訳す」だけで終わらせず、
その場で言えなかった一言を保存して、
あとでドリルできるようにするために作っています。
```

### 投稿2: フレーズ例

```text
現地で言えそうで言えない一言。

「先に席を取っておいて」
英: Can you grab us a table first?
中: 你先帮我们占个座吧

こういう一言を、その場で訳して保存しておくと次に使いやすいです。
```
